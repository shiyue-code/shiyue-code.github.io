Git Pull –Prune：自动清理失效的远程分支引用

随着项目的进行，远程仓库（如 GitHub/GitLab）上的许多分支会被合并并删除。然而，本地的远程跟踪分支（如 origin/feature-xxx）默认会一直保留，导致本地分支列表充斥着大量无用的“僵尸分支”。

git pull --prune （或简写为 git pull -p）可以在拉取最新代码的同时，自动清理本地那些在远程仓库已经被删除的分支引用。
