Visual Studio 条件断点配置及支持函数

在 Visual Studio 中调试 C++ 代码时，使用条件断点（Conditional Breakpoints）可以极大地提高定位特定 Bug 的效率。

1. 配置方法

  1. 在代码左侧边缘点击创建普通断点。
  2. 右键点击红色的断点图标，选择 **“条件…” (Conditions…)**。
  3. 勾选 **“条件表达式” (Conditional Expression)**。
  4. 设置判定规则（如：为 true / 更改时），并在输入框中填入 C++ 表达式。

2. 调试条件支持的内置字符串函数

对于 C++ 原生字符串或字符指针，VS 的调试求值引擎内置支持了以下轻量 C 风格字符串函数：

长度计算

  • strlen (单字节字符长度)
  • wcslen (宽字符长度)
  • strnlen
  • wcsnlen

字符串比较 (全匹配与大小写无关匹配)

  • strcmp (区分大小写比较)
  • wcscmp (宽字符区分大小写)
  • _stricmp (不区分大小写)
  • _wcsicmp (宽字符不区分大小写)
  • strncmp
  • wcsncmp
  • _strnicmp
  • _wcsnicmp

字符与子串查找

  • strchr (查找单个字符)
  • wcschr (宽字符查找单个字符)
  • strstr (查找子串)
  • wcsstr (宽字符查找子串)

3. 实用配置示例

场景 条件表达式 说明
匹配特定字符串值 strcmp(name, "TargetUser") == 0 当指针 name 指向的字符串为 "TargetUser" 时触发
大小写不敏感匹配 _stricmp(ext, ".txt") == 0 匹配 .txt、.TXT 等后缀
匹配子串 strstr(url, "api/v1") != nullptr 当 URL 中包含 "api/v1" 子串时触发
数组/指针越界防御 index >= max_limit 数值边界检查
空指针判断 ptr != nullptr 过滤空指针，仅在有效对象时停下
