Git Cherry-Pick 实战技巧

git cherry-pick 用于挑选指定的某些提交（Commit），并将它们作为新的提交应用到当前分支上。这在跨分支修 Bug（Hotfix）或局部提取功能代码时非常有用。

2. 特殊场景：应用“合并提交”（Merge Commit）

当尝试 cherry-pick 一个通过 git merge 产生的合并提交时，Git 会因为无法判断该将哪条分支上的修改作为基准而报错。此时必须使用 -m 选项来指定父分支编号：

NOTE
  • -m 1：代表合并的主线分支（通常是被合并入的分支）。
  • -m 2：代表合并的分支（通常是合并来源的 feature 分支）。
