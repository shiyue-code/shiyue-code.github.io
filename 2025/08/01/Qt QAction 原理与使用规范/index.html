QAction 原理与使用规范

QAction 是 Qt 中用于抽象“用户动作”（如新建文件、保存、复制等）的非可视化类。它允许将相同的操作绑定到菜单栏、工具栏以及快捷键上，并自动保持这些界面元素的状态同步。

1. 配合 QMenu 使用 (右键菜单示例)

NOTE
  • triggered 信号：当用户触发动作时发送（无论是否 Checkable）。
  • toggled 信号：仅在 setCheckable(true) 的状态下，其 isChecked() 发生改变时才会触发。

自动同步的状态与属性

当通过代码修改 QAction 的属性时，绑定它的所有控件会自动更新：

  • 状态同步：isChecked() (选中状态)、isVisible() (显示隐藏)、isEnabled() (启用禁用)。
  • 文本与图标：setText()、setIcon()、setToolTip() 都会自动传递到各关联按钮上。

3. QAction 底层机制

QAction 继承自 QObject，本身并不是一个 QWidget。

  • 关联机制：
    • 当调用 menu->addAction(action) 或 toolBar->addAction(action) 时，Qt 会把这些窗口容器或实际按钮的指针加入到 QAction 内部的关联对象列表中。
    • Qt6 之前：通过 QAction::associatedWidgets() 访问。
    • Qt6 之后：被通用化，通过 QAction::associatedObjects() 访问。
  • 物理渲染：
    • 在工具栏上，QToolBar 接收到 QAction 后，会在内部实际创建一个 QToolButton（其默认 Action 被设为该 QAction），由该按钮负责屏幕渲染与点击捕获。
  • 内存管理：
    • 必须为 QAction 分配 parent（如窗口本身），因为将其 addAction 到菜单或工具栏不会转移 QAction 的对象所有权（Ownership）。不指定 parent 会引发内存泄漏。
